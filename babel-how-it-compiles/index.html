Babel — how it compiles your JavaScript

your code→ ① parse→ AST→ ② transform (plugins)→ ③ generate→ old-browser code
INPUT — modern JS (editable)
Edit the code — the right side updates as you type. Click a token or AST node to highlight its source here.
The parser first cuts the text into tokens — the "words" of JavaScript. Spaces and comments are gone.
Then it arranges the tokens into a tree: the AST. Every node has a type. Plugins only ever see this tree, never your text.
preset-env is a bundle of small plugins. It compares your target with a compatibility table and switches on only the ones that target needs.

      
The generator walks the changed tree and prints it back out as text. Try different targets — same input, very different output.
