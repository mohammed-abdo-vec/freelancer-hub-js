Level 2 · Logic · Task 1

Functions: reusable recipes

Goal

Write small functions that take inputs (parameters) and give back an output (return). A function is a recipe: write it once, use it as often as you like.

You'll use

  • function name(param) { }
  • return
  • default parameters
  • (a, b) => a + b
function double(n) {   // n is the input
  return n * 2;         // this is the output
}
double(4);  // → 8
double(10); // → 20

Steps

  1. square(n) returns n times itself.
  2. celsiusToFahrenheit(c) returns c * 9 / 5 + 32.
  3. greet(name) returns "Hello, mohammed!". If no name is given, it returns "Hello, friend!".
  4. add, written as an arrow function, returns the sum of two numbers.
  5. priceWithTax(price, taxRate). The tax rate defaults to 0.15.
  6. Read the logDouble example at the bottom of the file and answer the question there.

return ≠ console.log. console.log shows a value to you. return hands the value back to the code so it can be stored or used again. Checks can only test what you return.

Think about it

  • Any code after return inside a function never runs. Why?
  • What does a function give back if it has no return at all?
