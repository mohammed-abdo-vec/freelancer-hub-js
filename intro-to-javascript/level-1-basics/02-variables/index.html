Variables: giving values a name

Goal

Store values in variables, change them, and join them into a sentence. A variable is a labelled box. The label is its name and the value goes inside.

You'll use

  • const
  • let
  • = (assign)
  • `template ${literals}`
  • age++
const city = "Riyadh";   // const: this box never gets a new value
let score = 10;          // let: this box can change
score = score + 5;       // now 15
console.log(`I live in ${city} and scored ${score}`);

Steps

  1. Make a const called firstName holding your first name.
  2. Make a const called lastName.
  3. Make a let called age holding a number.
  4. Make fullName using a template literal: first name, a space, last name.
  5. It's your birthday! Add 1 to age.
  6. Make intro: "Hi, I'm mohammed Ali and I'm 21 years old.", built from your variables. Then log it.
  7. Uncomment the last line in the file, refresh, and read the error.

Backticks, not quotes. Template literals use the ` key (top-left of most keyboards). ${ } only works inside backticks.

Think about it

  • Why is firstName a const but age a let?
  • Names are case-sensitive. Is firstname the same variable as firstName?
  • Use const by default. Switch to let only when the value really needs to change.
Bonus

Make a let called favoriteColor, log it, change it, and log it again. Every console.log shows the value at that moment.
