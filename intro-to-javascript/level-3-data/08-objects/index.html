Level 3 · Data · Task 2

Objects: things with properties

Goal

An array holds items in order. An object holds named values: a student has a name, an age and a list of courses. Almost every piece of data on the web (users, products, posts) is an object.

You'll use

  • { key: value }
  • obj.key
  • obj["key"]
  • adding properties
  • Object.keys()
const car = { brand: "Toyota", year: 2020 };
car.brand;       // "Toyota"   (dot notation)
car["year"];     // 2020       (bracket notation)
car.color = "white";   // adds a new property

Steps

  1. studentName: read the name with dot notation.
  2. studentAge: read the age with bracket notation and the variable key.
  3. Add an email property to student.
  4. Add "JavaScript" to the student's courses array.
  5. describe(person) returns "mohammed is 20 and takes 3 courses.". It must work for any person object.
  6. Make your own book object with title, author, pages (a number) and isRead (a boolean).
  7. countKeys(obj) returns how many properties an object has.

Dot or brackets? Use dot notation when you know the name as you write the code. Use brackets when the name is stored in a variable, like student[key]. student.key looks for a property literally called "key".

Think about it

  • What do you get when you read a property that doesn't exist, like student.phone?
  • Look at student.courses.length: dot, then dot again. What is each step reading?
