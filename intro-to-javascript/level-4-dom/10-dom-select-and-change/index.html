    Goal

    Until now JavaScript only talked to the console. Now it changes the page. The browser turns your HTML into a tree of objects called the DOM. JavaScript can find any element in that tree and change it.

    You'll use

    • document.querySelector()
    • querySelectorAll()
    • .textContent
    • .classList.add()
    • createElement()
    • .append()
    const heading = document.querySelector("#title");  // same selectors as CSS!
heading.textContent = "New text";
heading.classList.add("big");

    Steps

    1. Select #title and change its text to your name.
    2. Select the .subtitle and set its text to "Learning JavaScript".
    3. Add the class highlight to #card. Watch the card change.
    4. For each skill in the skills array, create an <li>, set its text, and add it to #skills.
    5. Select all the .note paragraphs and put a number in front of each one: "1. Practise every day".

    Inspect it. Right-click the card and choose Inspect. The Elements panel shows the DOM after your JavaScript ran, which isn't always the same as your HTML file.

    Think about it

    • What does querySelector return when nothing matches? What happens when you then try to set .textContent on it? (Try a typo like "#tittle".)
    • Why use classList.add instead of element.style.border = …? Where should the styling live?
    Bonus

    Try innerHTML instead of textContent with "<em>mohammed</em>". What's the difference? Why is innerHTML dangerous with text that users typed?
